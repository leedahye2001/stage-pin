# MY 화면 구성·기술 결정

2026-11-06 로컬 소스 기준. 홈·굿즈와 같은 화면 언어를 적용하고 계정 저장 동작은 유지한다.

## 구성

1. MY 제목과 간결한 프로필: 닉네임, 제공된 경우에만 이메일, 로그아웃. 카카오 재연동 버튼과 저장 위치 설명은 제거했다. 로그인하지 않았다면 기존 공식 카카오 버튼을 유지한다.
2. 찜한 공연 / 관심 아티스트 / 내 등록 굿즈 / 찜한 굿즈: 홈의 중립색 pill 필터를 재사용하고 한 목록씩 표시한다. 최초 선택은 찜한 공연이다. 네 종류의 빈 박스를 연속해서 보여주지 않는다.
3. 선택한 목록: 공연은 기존 ConcertCard, 굿즈는 GoodsCard, 아티스트는 홈과 같은 ArtistPhoto를 사용한다. 사진 크레딧은 선택 목록의 기존 모달로 접근할 수 있다.
4. 하단 보조 메뉴: 기기 찜 가져오기와 관리자 공지 검수는 큰 홍보 카드 대신 작은 행으로 둔다. 기기 찜 가져오기는 실행 직전에만 확인창을 띄우며 자동 병합하지 않는다.

## 일관성 기준

- marketStyles와 responsiveStyles.content로 홈·굿즈와 같은 모바일 20px / 큰 화면 32px 패딩·컨테이너를 사용한다. 좁은 화면은 두 열, 큰 화면은 기존 responsiveLayout의 카드 폭·열 수를 따른다.
- 흰 배경·회색 버튼·검정 선택 필터를 사용하고 보라색은 하트와 최종 확인 등 핵심 동작에만 사용한다. 점선 박스와 반복 안내문은 제거했다.
- profile/search 모양을 모든 로딩에 사용하지 않는다. 계정은 56px 프로필+텍스트+버튼, 공연은 포스터 격자, 굿즈는 실제 사진 높이의 격자, 아티스트는 66px 사진 행으로 맞춘다. 기존 LoadingSkeleton에 종류/격자 옵션만 확장해 다른 화면의 기본 동작을 보존한다.
- 이메일이 없다는 안내를 필수 프로필 필드처럼 보여주지 않는다. 프로필 조회 실패를 비로그인으로 오인하거나 재시도 없이 계속 스켈레톤으로 표시하지 않는다.

## 상태·데이터 결정

- collectionViewState 순수 함수로 인증 확인/로그인 필요/목록 로딩/실패/빈 목록/기존 콘텐츠를 구분한다. 조회 실패가 있을 때 빈 목록으로 표현하지 않고 재시도한다. 백그라운드 재조회 실패 시 기존 데이터는 유지한다.
- 내 등록 굿즈는 해당 탭을 선택하고 로그인한 경우에만 조회한다. 기존 infinite query와 더 보기를 유지한다. 화면 구성을 바꾸기 위해 저장 API나 세션 권한을 변경하지 않았다.
- MemberLoginCard는 굿즈 등록의 로그인 진입점에도 사용된다. 공식 버튼·로그인 성공 안내·오류/재시도·로그아웃 처리는 보존했고 사용자가 제거를 요청한 재연동 UI만 제거했다. 서버의 동의·프로필 조회 계약을 삭제한 것은 아니다.
- 기기 찜 확인창의 '취소'는 저장을 실행하지 않는다. 가져오기 이후의 서버 실패는 기존 공통 오류 안내를 사용한다. 기기 원본 보존·중복 제외 정책은 account-favorites.md와 같다.

## 검증

- my-collections.test.mjs에서 로딩/인증/실패/빈 목록의 분리, 재조회 중 기존 콘텐츠 유지, 목록별 스켈레톤 매핑을 검사한다.
- UI 확인은 사용자 찜을 바꾸지 않고 목록 필터 전환과 기기 찜 확인창 취소로 진행한다. 실제 가져오기·로그아웃은 디자인 검증 때문에 실행하지 않는다.
- 웹 검사와 실기기 검증은 구분한다. 운영 push·배포·iPhone 재빌드는 별도 요청 범위다.

2026-11-06: lint·타입 검사·Node 테스트 62개·웹 export 통과. 8081에서 실제 로그인 상태의 네 목록 전환, 공연/아티스트 카드, 내 등록 굿즈·찜한 굿즈의 빈 상태, 기기 찜 확인창 취소를 확인했다. 제거 대상 문구는 DOM에 없고 좁은 화면 CSS 폭 392px에서 문서 가로 넘침이 없음을 확인했다. 큰 화면 레이아웃도 확인한 뒤 임시 viewport 설정을 복원했다. 사용자 찜·등록 글과 로그인 상태는 변경하지 않았다. 느린 네트워크·오류 UI의 실제 렌더링과 iPhone 실기기는 별도로 검증하지 않았으며 상태 분기는 단위 테스트로 검사했다.
