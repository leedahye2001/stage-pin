# 인기 검색어

- 검색창에 포커스하면 10개 순위를 표시한다. 입력하면 기존 아티스트 자동완성으로 전환한다.
- 항목 선택은 공연 검색으로 이동한다. 검색 확정/아티스트 선택만 집계하며 입력·조회·찜은 집계하지 않는다.
- `GET /api/v1/search/popular`: 누적 횟수 내림차순, 동률은 초기 순서. 모두 0이면 `initial=true`.
- `POST /api/v1/search/popular`: `{ "query": "데이식스" }`. DB에서 원자적으로 증가한다.
- 초기 대상은 DAY6, BTS, SEVENTEEN, IVE, aespa, NCT, Stray Kids, TXT, ENHYPEN, LE SSERAFIM이다. 한/영 별칭은 같은 카운터로 합친다.
- 임의 검색 문자열은 저장하지 않는다. 사용자 ID/IP/검색 이력은 이 기능의 DB에 저장하지 않는다.
- 현재는 지정한 10개 아티스트 안에서의 누적 검색 순위이며 전체 검색어/실시간/순 방문자 순위가 아니다. 반복 검색도 집계되므로 조작 방지와 기간별 순위는 후속 과제다.
- 집계 전에는 초기 추천 순서라고 표시한다. API 실패 시 가짜 순위로 대체하지 않고 재시도 UI를 제공한다.
- 웹 입력의 기본 파란 외곽선 대신 검색창 테두리를 진한 회색으로 바꿔 포커스를 표시한다. 닫기 버튼/Escape를 지원한다.

로컬 확인: Docker API 실행 후 `http://localhost:8081/`에서 빈 검색창을 누른다. 초기 데이터는 Flyway V5로 추가하며 재시작해도 누적 횟수를 초기화하지 않는다.
