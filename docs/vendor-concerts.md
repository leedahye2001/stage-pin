# 홈 예매처별 공연 일정

- 홈 아티스트 사진 목록은 제거한다. 찜은 기존 상단 아티스트 검색과 MY에서 관리하며, 관심 공연 섹션은 그대로 유지한다.
- 관심 공연 아래에 전체·NOL·YES24·멜론티켓·티켓링크·기타 필터와 가로 공연 카드를 둔다.
- 임시 추천 검색어는 DAY6/데이식스, BTS/방탄소년단, SEVENTEEN/세븐틴, IVE/아이브, aespa/에스파, NCT/엔시티다. 실제 검색량 집계나 인기 순위가 아니다.
- 기존 KOPIS 검색 결과를 공연명/아티스트명으로 대조하고, 진행·예정 우선 및 완료 최근순 기준 아티스트별 2개, 최대 12개의 상세 정보를 조회한다. 중복 공연 ID는 제거한다.
- 예매처는 KOPIS 상세의 실제 `ticketLinks` URL 호스트로 분류한다. 여러 예매처가 있으면 각각의 탭에 나타난다. 링크 없는 공연은 전체에서만 보이며 임의 예매처를 부여하지 않는다.
- 확인된 예매처라도 현재 판매 중이라는 뜻은 아니다. 기존 요청대로 완료 공연과 완료 배지도 함께 표시한다. 선예매/일반예매 날짜를 추정하거나 생성하지 않는다.
- 전체는 목록 데이터부터 표시할 수 있다. 검색 요청이 끝난 뒤 상세를 조회한다. 예매처 필터는 상세 조회 중 스켈레톤, 오류 시 재시도, 확인 결과가 없으면 빈 상태를 표시한다. 원본 링크가 없거나 기존 상세 fallback 응답이 캐시된 경우를 위해 빈 예매처 탭에서 상세를 강제로 재조회하는 버튼도 제공한다.
- 검색 5분·상세 30분 캐시와 기존 관심 공연/상세 query key를 재사용한다. API의 검색 기간/개수 제한, 원본 출연진·예매처 누락은 그대로 남는다. 대규모 운영에서는 이 조회를 서버 배치 수집·캐시로 이전해야 한다.
