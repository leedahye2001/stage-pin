# 홈 공연 추천

- `GET /api/v1/concerts/home`만 홈에서 사용한다. 일반 검색·공연장 탐색 API는 변경하지 않는다.
- 오늘부터 30일 동안 KOPIS 대중음악 목록을 페이지당 100개, 최대 3페이지 조회한다. 중복 공연 ID와 종료·취소 공연은 제외한다.
- 공연명에서 팬미팅·팬콘(100), 단독 콘서트·단독공연(90), 월드/아시아/전국/라이브 투어(60), 콘서트·내한·쇼케이스(30), 밴드·페스티벌(15) 중 가장 높은 점수를 사용한다. 공백·구분점·대소문자는 정규화하며, FANCON과 FAN CONCERT 같은 표현 차이로 점수를 중복 가산하지 않는다.
- 할로윈·클럽파티·나이트·헌정·발표회·창립행사 등의 명시적 근거는 -100으로 후순위에 둔다. 같은 점수에서는 가까운 공연일, ID 순이다.
- 상위 12개만 출연진·공연장·예매처 상세를 조회하고 30분 캐시한다. 상세 조회 실패 시 목록 정보로 표시한다. 새 홈 후보도 상세 페이지에서 조회할 수 있도록 캐시에 포함한다.
- 프론트는 추천 순서를 유지하고, 찜 필터 및 종료 여부를 추가로 적용한다. 기존 선예매·일반예매 데이터와 날짜는 변경하지 않는다.

## 한계

인기순·실제 아이돌 여부 판정이 아닌 **공연 유형 적합도 기반 추천**이다. KOPIS 등록 누락, 30일/300건 밖의 공연, 제목에 유형 정보가 없는 가수 공연은 빠지거나 후순위가 될 수 있다. 출연진 수만으로 SOLO를 부여하는 기존 fanCategory는 추천에 쓰지 않는다. 유명 가수 명단을 하드코딩하지 않는다. 필요하면 검증된 아티스트 식별 데이터와 평가셋으로 확장한다. 일부 가수의 할로윈 공연도 후순위가 될 수 있으나 일반 검색에서는 제외하지 않는다.
