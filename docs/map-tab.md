# 지도 탭

- 하단·데스크톱·iOS 탭 이름은 지도이며, 기존 `/explore` 주소는 유지한다.
- 공연 장소는 기존 KOPIS 추천 공연 API 결과와 기기에 찜한 공연을 병합·중복 제거해 표시한다. 전국 모든 공연장 데이터나 주변 공연 전체 검색을 뜻하지 않는다.
- 좌표가 확인된 공연을 장소별로 묶고, 장소 선택 → 해당 공연 목록 → 공연 상세로 이동한다.
- 현장 교환은 준비 중 화면이며 실제 교환 상대·위치 데이터는 연결하지 않았다.

## 웹 현재 위치

- 지도 탭의 실제 지도 진입 시 브라우저의 단발성 위치 조회를 요청한다. 처음에는 사용자 허용이 필요하다.
- 허용하면 카카오맵 또는 OpenStreetMap 기반 지도 중심과 확대 수준을 현재 위치로 변경한다. 받은 위치로 실제 직선 거리(km)를 계산하고 장소 목록을 가까운 순으로 정렬한다. 이동 시간·길거리 거리는 아니며 주변 공연을 새로 수집하지 않는다.
- 현 위치 버튼으로 다시 조회할 수 있고, 발자국 보기에서도 누르면 실제 지도로 전환한다.
- 위치는 컴포넌트 메모리에서만 사용한다. 서버·로컬 저장소·분석 이벤트에 보내거나 다른 사용자에게 공개하지 않는다. 지도 제공자의 타일/SDK 요청은 해당 서비스 정책을 따른다.
- 권한 거부·시간 초과·미지원 브라우저는 메시지를 표시하고 전국 지도·장소 목록을 유지한다. HTTPS 또는 localhost에서 이용한다.
- `watchPosition`이나 백그라운드 위치 추적은 사용하지 않는다.
- 네이티브 지도는 기존 Apple Maps/Google Maps를 유지하며 이번 현재 위치 기능은 웹에만 적용했다. iPhone 앱 재빌드·배포는 하지 않았다.

검증: lint, TypeScript, 단위 테스트(장소 그룹화·잘못된 좌표·위치 허용/거부/시간 초과), 웹 export. 실제 기기의 위치 정확도와 네이티브 위치 권한 동작은 별도 검증이 필요하다.

## 공연 장소 탐색 UI

- NOL 지도 탐색의 필터·지도 마커·목록 연결 방식을 참고하되 숙박 가격 대신 장소 이름·공연 수를 표시한다. NOL 데이터·자산을 가져오지 않는다.
- 상단 제목은 '지도' 하나만 유지한다. 검색은 현재 불러온 데이터의 장소·주소·공연명·아티스트명에 적용하며 기존 추천 아티스트의 한영 별칭을 사용한다.
- 전체 기간 / 오늘 / 7일 이내 / 이번 달, 지역, 찜한 공연 필터를 조합한다. 기간은 화면 진입 시 한국 날짜 기준이며 전체 기간 외에는 오늘 이후와 겹치는 공연만 포함한다. 취소·잘못된 날짜는 기간 검색에서 제외한다.
- PC·태블릿은 왼쪽 스크롤 목록과 오른쪽 지도, 모바일은 지도와 그 아래 장소 목록으로 배치한다. 모바일 목록은 드래그 가능한 시트가 아니라 스크롤 콘텐츠다.
- 선택한 장소의 마커를 보라색으로 강조하고 지도를 이동한다. 장소별 포스터·완료/진행 중/예정/취소 상태·일정·찜과 공연 상세 이동, 카카오 길찾기 링크를 제공한다.
- 지도 탭에서는 발자국 전환 버튼을 숨기지만 다른 화면의 발자국 기능은 보존한다. Kakao SDK 맵은 선택마다 재생성하지 않고 마커만 갱신한다.
- 현장 교환은 실제 상대·위치 데이터가 없으므로 가짜 핀이나 사람 수를 표시하지 않는다. 현장 거래 필터가 적용된 기존 굿즈 목록으로 이동할 수 있다.
- 기존 네이티브 지도 제공자는 유지하고 선택 위치 카메라 이동만 보완했다. 이번 UI의 네이티브 재빌드·실기기 검증은 별도다.
