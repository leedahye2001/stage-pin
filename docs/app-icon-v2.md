# 앱 아이콘 V2 시안

## 디자인

보라색 바탕과 흰색 핀의 명확한 대비로 작은 런처 아이콘에서도 위치 핀을 알아볼 수 있도록 한다. 핀 안에는 공연의 정체성을 나타내는 두 조명과 평평한 무대를 남긴다. 기존 광택, 작은 조명 점, 원통형 무대, 입체 그림자는 제거한다. 화면 상단 로고는 변경하지 않는다.

## 파일

- 원본: `mobile/assets/stagepin-app-icon-v2.png` — 1024×1024 PNG
- 미리보기: 상위 outputs의 `stagepin-app-icon-refined.png` — 256×256
- 작은 크기 확인: 상위 outputs의 `stagepin-app-icon-48.png` — 48×48

기존 `stagepin-icon.png`는 보존한다. 현재는 디자인 검토용 시안이며 설치된 앱이나 운영 웹의 아이콘은 교체하지 않았다.

## 생성 기록

내장 imagegen 편집 사용. 기존 StagePin 아이콘을 참조하여 다음 지시로 생성했다:

> StagePin의 위치 핀과 공연 무대라는 핵심 개념을 유지한다. 가장자리까지 채우는 보라색 바탕(#7046DF)에 흰색 핀을 중앙 배치한다. 내부는 평평한 흰 무대와 두 개의 단순한 밝은 보라색 조명으로 정리한다. 작은 크기에서도 읽히는 기하학적 형태와 여백을 사용한다. 광택·3D·그림자·텍스처·반짝이·문구는 추가하지 않는다.

생성 원본은 1024×1024로 리사이즈했으며, 48×48 축소본을 시각적으로 확인했다. 실제 iOS/Android 마스킹 및 홈 화면 배치 검증은 기기 반영 단계에서 진행한다.
