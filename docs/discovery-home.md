# 공개 탐색형 홈 프로토타입

홈은 로그인 여부나 찜한 아티스트 유무와 관계없이 공연·굿즈를 탐색하는 진입점이다. 개인 일정 관리는 일정/MY에 남긴다.

## 화면 순서

1. 기존 검색: 아티스트·공연 검색을 유지한다. 굿즈 통합 검색은 이번 범위가 아니다.
2. 공연 포스터 캐러셀: 실제 포스터가 있는 공개 공연 최대 5개. 5초 자동 넘김, 좌우 스와이프, 이전/다음·일시정지, 상세 이동을 제공한다.
3. 곧 티켓 오픈: 검증일·원문·예매 링크가 있는 미래 선예매/일반예매만 시간순으로 표시한다. 데이터가 없으면 영역을 숨긴다.
4. 공연 둘러보기: 찜 여부와 무관한 예정·진행 중 공연. 전체/예정/진행 중 필터와 `/discover` 목록 페이지를 제공한다.
5. 굿즈 목록: 실제 공개 등록 글만 표시한다. 글이 없으면 등록 진입점을 제공한다.
6. 찜한 아티스트 공연: 찜한 아티스트가 있을 때만 보조 영역으로 최대 4개 표시한다. 전체 보기는 기존 관심 공연 페이지다.
7. 현장 교환: 관련 공개 글이 있을 때만 표시한다.

## 데이터 범위와 제한

- 공개 공연은 기존 홈 추천 API의 제한된 결과(현재 최대 12개)를 재사용한다. 전국 모든 공연을 가져오거나 실제 인기 순위를 계산하는 기능이 아니다.
- KOPIS/StagePin 출처의 유효한 날짜를 가진 예정·진행 중 공연만 공개 탐색에 포함하고, ID 중복을 제거한다. 현재 직접 등록 공연 승인 API는 없어 실제 공연 데이터는 KOPIS다.
- 종료 공연은 검색·관심 아티스트 공연 기록에서 계속 조회할 수 있다. 공개 탐색 상단에는 넣지 않는다.
- 날짜 상태는 화면을 연 시점 기준이다. 장시간 열어두면 새로고침이 필요하다.
- 예매 오픈 시각·링크·굿즈는 임의 생성하지 않는다. 확인된 오픈 일정이 없으면 해당 홈 섹션이 보이지 않는 것이 정상이다.
- 기존 공연 상세 출처·이미지 이용 정보는 유지한다.

## 검증 범위

공개 공연 필터/정렬/중복 제거와 검증된 미래 예매 일정 선택을 단위 테스트한다. 모바일 폭·데스크톱 웹에서 캐러셀과 목록 이동을 확인한다. iPhone 네이티브 재빌드 및 운영 배포는 별도 작업이다.
