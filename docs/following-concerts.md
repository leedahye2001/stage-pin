# 관심 아티스트 공연 영역

- 홈 제목: 좋아하는 아티스트의 공연 일정. 전체/찜 필터는 제거하고 전체 공연·선예매·일반예매 탭만 표시한다.
- 전체 공연은 전역 추천 12개를 필터링하지 않고, 찜한 아티스트의 대표 이름·검색 이름·한국어 별칭 하나로 KOPIS 검색 API를 조회해 합친다. 정규화한 동일 검색어와 공연 ID는 중복 제거하고 예정/진행 공연을 날짜순으로 표시한다.
- 출연진의 ID/이름/별칭을 비교하고, 출연진이 비면 공연명도 확인한다. 영문 이름은 문자 경계를 확인해 IVE를 LIVE로 오인하지 않는다. 이름 기반 매칭이므로 동명이인 등은 완벽하게 구분하지 못한다.
- 공연 검색 API의 기존 조회 범위·결과 수 제한은 그대로 적용된다. 검색 결과가 모든 공연을 보장하지는 않는다.
- 선예매·일반예매는 확인된 예매 오픈 데이터 중 관심 아티스트의 일정만 사용한다. 임박 강조 및 실제 알림 발송은 이번 범위가 아니다.
- 전체 보기는 `/following-concerts`에서 동일한 관심 아티스트 목록을 보여준다.

## 직접 등록 공연

등록·승인 API는 아직 없다. 현재 실데이터는 KOPIS이며, 샘플 등록 공연은 섞지 않는다. 병합 함수는 향후 **서버가 승인 후 공개한** `source=STAGEPIN` 공연을 받을 수 있지만, 서버의 등록·검수·공개 API와 연결되기 전에는 해당 데이터가 들어오지 않는다. 프론트 필터가 승인 권한을 대체하지 않는다. KOPIS/직접 등록 간 서로 다른 ID의 중복 연결은 추후 서버의 KOPIS ID 연결로 처리해야 한다.
