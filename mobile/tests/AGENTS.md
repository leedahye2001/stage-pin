# 클라이언트 테스트

- 기존 `node:test` 테스트를 유지한다. 실행 명령·런타임 기준은 `mobile/AGENTS.md`를 따른다.
- `.mjs` 테스트에서 순수 `.ts` 유틸리티를 직접 import하는 기존 방식을 따른다. 필요 시 기존 `registerHooks` 사용 사례를 참고하고 경고 제거를 위해 package.json 모듈 체계를 바꾸지 않는다.
- 실제 브라우저·스토리지·외부 API에 의존하지 않는 고정 입력으로 검증한다. 시각·GPS·응답 실패는 입력/모의 객체로 제어한다.
- 필터·별칭·상태 배지·시간대·좌표/거리·중복 저장·가격/사진 검증은 경계 조건까지 확인한다. 존재하지 않는 거리를 기대값으로 넣지 않는다.
- 반응형 변경은 breakpoint 전후와 반올림된 분수 viewport에서 카드가 컨테이너를 넘지 않는지 검사한다.
- 이 테스트는 React Native 실기기/UI 렌더링을 검증하지 않는다. 별도로 lint/tsc, 웹 빌드·화면, 필요 시 네이티브 실행을 확인한다.
