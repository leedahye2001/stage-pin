# 이미지·브랜드 자산

- `app.json` 및 실제 import에서 쓰는 파일을 확인하고 교체한다. 아이콘·splash·favicon·Android 레이어는 서로 다른 용도다.
- 사용자가 선택한 기존 로고 형태를 요청 없이 재디자인하지 않는다. 웹 로고와 앱 아이콘의 배경/투명도 요구를 구분한다.
- 새 자산은 출처·라이선스를 확인하고 `docs/brand-assets.md` 등 해당 문서에 기록한다. 출처 불명 연예인 사진·타사 로고를 임의로 번들에 넣지 않는다.
- 사진 라이선스 메타데이터는 외부 응답과 정보 UI에서 유지한다. 자산 폴더로 복사했다고 표시 의무가 없어지는 것은 아니다.
- 앱 아이콘 교체는 웹 재배포만으로 설치된 네이티브 앱에 반영되지 않는다. 적용 범위와 재빌드 필요성을 구분해 보고한다.
- 생성된 iOS/Android 자산만 고쳐 원본 설정과 불일치시키지 않는다. 참조/원본을 먼저 확인한다.
