# 화면·라우팅

- 이 폴더에는 Expo Router 화면과 `_layout.tsx`만 둔다. 공통 UI는 `components`, 순수 로직/상태는 `lib`, HTTP는 `api`로 분리한다.
- 네비게이션은 Expo Router를 사용한다. `(tabs)`와 상세/검색/인증 callback의 독립 경로를 유지한다.
- 주요 탭은 지도 → 일정 → 홈 → 굿즈 → MY 순서다. 로그북은 숨김 상태를 유지한다. iOS와 일반 AppTabs 구현을 함께 확인한다.
- 화면 제목은 간결하게 유지한다. 요청 없는 영어 장식 문구·슬로건·설명용 소제목을 추가하지 않는다.
- API 로딩은 기존 Skeleton 컴포넌트를 사용한다. 오류·빈 목록·권한 거부를 구별하고 데이터를 가공해 성공처럼 보이지 않게 한다.
- 홈의 관심 아티스트 공연에는 과거 공연도 포함하고 상태 배지를 유지한다. 예매 시작일은 검증된 일정만 연결한다.
- 내 일정 저장과 찜을 구분한다. 공연·예매 일정의 표시와 외부 예매 링크 이동을 실제 예매 완료로 표현하지 않는다.
- 굿즈 등록은 숫자 가격, 코드 기반 상태 선택, 필수 사진 검증을 유지한다. 실제 업로드/거래 기능과 로컬 미리보기를 혼동하지 않는다.
- 지도는 확인된 공연장 좌표만 표시한다. 현 위치 실패 시 안내와 탐색 가능한 대체 상태를 제공하고 임의의 내 위치를 생성하지 않는다.
- 모바일 safe area/하단바 여백을 보존하고 데스크톱은 공통 반응형 레이아웃을 사용한다. 관리자 입력·프로필·위치 데이터를 Analytics로 보내지 않는다.
