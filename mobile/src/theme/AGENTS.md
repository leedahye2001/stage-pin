# 디자인 토큰

- `tokens.ts`의 colors/spacing/radius/typography가 공통 기준이다. 화면마다 비슷한 토큰 집합을 새로 만들지 않는다.
- 기본 배경은 흰색, 보조 표면·중립 버튼은 회색, 선택·핵심 강조는 보라색을 유지한다. 성공/경고 등 의미 색을 보라색으로 덮지 않는다.
- 토큰 변경은 전체 화면에 영향을 준다. 홈·지도·일정·굿즈·MY 및 주요 상세의 대비·읽기·선택 상태를 확인한다.
- 특정 화면의 일회성 값 때문에 공통 토큰 의미를 바꾸거나 사용하지 않는 테마 체계를 추가하지 않는다.
