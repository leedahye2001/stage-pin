# 굿즈 등록·조회

- 공개 목록/상세/사진과 로그인 필수 등록/내 글을 구분한다. 작성자는 세션으로 결정하고 요청 owner/seller를 신뢰하지 않는다.
- Cookie 쓰기는 정확한 웹 Origin을 확인한다. 네이티브 Bearer는 기존 StagePin 세션을 검증한다.
- 사진은 실제 디코딩 가능한 JPEG/PNG만 받아 제한된 크기로 재인코딩한다. EXIF/GPS·원본 파일명·외부 URL을 그대로 공개하지 않는다.
- 사진 1~5장 검증·변환 후 글/사진을 한 트랜잭션으로 저장한다. `(owner_id, request_id)`의 중복 방지를 유지한다.
- 목록/상세 쿼리에 사진 BYTEA를 포함하지 않는다. 목록은 유한한 페이지 크기를 유지한다.
- PostgreSQL 사진 저장은 소규모 단계의 선택이다. 큰 트래픽에는 객체 저장소로 분리하고 결제·채팅·거래 완료 기능과 혼동하지 않는다.
- 이미지 검증·작성자 권한·롤백·재조회 테스트를 생략하거나 보안 검사를 완화해 해결하지 않는다.
