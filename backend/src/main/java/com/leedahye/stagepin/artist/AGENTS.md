# 아티스트 카탈로그·이미지

- 현재 경로는 MusicBrainz 이름/별칭/ID → Wikidata 이미지 연결 → Wikimedia Commons 이미지·라이선스 메타데이터다. Spotify 키나 유료 구독을 요구하는 경로로 되돌리지 않는다.
- 영문·한글·공백·별칭 매칭과 안정적인 외부 식별자를 유지한다. 특정 인기 가수만 하드코딩해 전체 검색을 대체하지 않는다.
- `ArtistCatalogClient`의 User-Agent, 요청 간격, 캐시를 보존한다. 검색 입력마다 외부 서비스에 무제한 호출하지 않는다.
- 이미지 URL만 전달하지 말고 원문 페이지·저작자·라이선스 정보를 함께 유지한다. 허용 라이선스와 메타데이터 검증에 실패하면 사진 대신 기본 아이콘을 사용한다.
- 출처가 불분명한 검색 엔진 썸네일·팬 계정 사진으로 누락을 채우지 않는다. 모든 가수의 최신 공식 프로필을 제공한다고 보장하지 않는다.
- 외부 카탈로그 ID와 DB `Artist` ID는 같은 체계라고 가정하지 않는다.
- 연동 조건 변경은 `docs/artist-profile-sources.md`와 `ArtistCatalogClientTest`를 함께 확인한다.
